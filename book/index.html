CHAPTER 01

先决定要造什么

Mini SD Lab 是一台可以拆开的微型图像/视频生成机器：亲自训练一个图像压缩器、两个独立的噪声预测器，再从纯噪声回到图片和短视频。

首先看清边界。这不是 Stable Diffusion 官方权重的轻量复刻，也没有 MiniMax H3 的语义能力。今天能够验证“梯度真的更新、文件真的可解码”；好看的真人角色、长时间动作、实时桌面互动都不在承诺内。

本书采用“原理 → 对应源码 → 验证命令”的顺序。图像生成使用二维卷积；视频生成使用沿时间轴也卷积的三维网络，并非把单张图复制四次。两种生成都依赖同一个逐帧图像 VAE，但扩散权重彼此独立。

怎样判断“做完了”

文件存在不是画质合格。最低技术验收是：训练后的权重发生变化；新进程可以加载检查点；生成的 PNG 可被图像库打开；生成的 MP4 有真实 H.264 视频流及目标帧数。画质、文本遵循度和时间连续性必须在服务器上用授权数据另行评估。

CHAPTER 02

把图片压成潜变量：VAE

如果直接对每一个 RGB 像素去噪，计算量随空间大小迅速增加。VAE 先把图片的宽高各缩成四分之一、通道变成四个；去噪网络只处理这个更小的潜空间。推理的最后一步再用同一 VAE 把潜变量翻译回 RGB。

编码器输出两组值：均值 μ 和对数方差 log σ²。训练时从该分布采样，解码后比较与原图的像素误差；同时用 KL 项防止潜变量分布漂移。损失 = MSE(重建图, 原图) + kl_weight × KL。这里的 kl_weight=0.001 是本项目默认配置，不是普适最优值。

为什么先训练 VAE？如果解码器连红方块都无法还原，扩散器即使完美预测噪声，也没有办法输出清晰图。图像/视频扩散器随后共享这套 VAE，但训练扩散器时将 VAE 冻结。

下面是完整的 VAE 类源码。看 encode 的重参数化和 decode 的 Tanh 边界；训练循环在附录的 CLI 源码 train_vae 中。

class TinyVAE(nn.Module):  # 将像素压到四分之一空间分辨率的变分自编码器。
    def __init__(self, base: int = 32, latent_channels: int = 4):  # 允许按显存缩放宽度。
        super().__init__()  # 注册父类的参数管理能力。
        self.base = base  # 保留宽度以便写入检查点配置。
        self.latent_channels = latent_channels  # 保留潜变量通道配置。
        self.encoder = nn.Sequential(  # 建立两次下采样的像素编码器。
            nn.Conv2d(3, base, 3, padding=1), nn.SiLU(),  # 将 RGB 投影到隐藏特征。
            nn.Conv2d(base, base, 4, stride=2, padding=1), nn.SiLU(),  # 将边长减半。
            nn.Conv2d(base, base * 2, 4, stride=2, padding=1), nn.SiLU(),  # 再将边长减半。
            nn.Conv2d(base * 2, latent_channels * 2, 3, padding=1),  # 同时预测均值与对数方差。
        )  # 完成编码器定义。
        self.decoder = nn.Sequential(  # 建立与编码器空间尺寸对应的解码器。
            nn.Conv2d(latent_channels, base * 2, 3, padding=1), nn.SiLU(),  # 扩展潜变量通道。
            nn.ConvTranspose2d(base * 2, base, 4, stride=2, padding=1), nn.SiLU(),  # 恢复两倍边长。
            nn.ConvTranspose2d(base, base, 4, stride=2, padding=1), nn.SiLU(),  # 再恢复两倍边长。
            nn.Conv2d(base, 3, 3, padding=1), nn.Tanh(),  # 输出 [-1,1] 的 RGB 像素。
        )  # 完成解码器定义。

    def encode(self, image: torch.Tensor, sample: bool = True):  # 返回潜变量及分布参数。
        mean, logvar = self.encoder(image).chunk(2, dim=1)  # 沿通道拆出均值和对数方差。
        logvar = logvar.clamp(-10.0, 10.0)  # 防止标准差溢出或数值下溢。
        z = mean + torch.exp(0.5 * logvar) * torch.randn_like(mean) if sample else mean  # 训练时重参数化，推理时取均值。
        return z, mean, logvar  # 交还可用于重建与 KL 损失的量。

    def decode(self, latent: torch.Tensor) -> torch.Tensor:  # 从潜变量还原 RGB 图像。
        return self.decoder(latent)  # 输出范围由 Tanh 保证为 [-1,1]。

    def forward(self, image: torch.Tensor):  # 统一提供训练所需的重建结果。
        z, mean, logvar = self.encode(image)  # 执行变分编码。
        return self.decode(z), mean, logvar
CHAPTER 03

前向加噪与反向采样

扩散模型不是直接画画。训练时先选一个时间步 t，采样纯高斯噪声 ε，把干净潜变量 z₀ 变成 zₜ = √ᾱₜ · z₀ + √(1−ᾱₜ) · ε。网络学习预测刚刚加入的 ε。知道 ε 后，推理才能从随机噪声逐步还原潜变量。

本项目用线性 β 计划构造 ᾱ 表；用均方误差训练 ε 预测；使用确定性的 DDIM（η=0）跳步采样。采样步数不能超过训练噪声时间表。--seed 固定初始随机噪声，但不同设备/库版本不保证跨设备逐位相同。

train_step 每调用一次才更新一次权重；模型的损失下降与观众觉得好看是不同的判断。sample 里对每个时间点计算预测噪声、估计干净潜变量，再得到上一时间点状态。以下是完整的扩散调度器源码。

class Diffusion:  # 保留独立于模型权重的扩散噪声时间表。
    def __init__(self, timesteps: int = 100):  # 配置训练扩散的离散步数。
        if timesteps < 2:  # 避免只有一步时无法定义有效噪声过程。
            raise ValueError("扩散步数至少为 2")  # 提示可修复的配置错误。
        self.timesteps = timesteps  # 记录检查点必须复现的训练参数。
        betas = torch.linspace(0.0001, 0.02, timesteps, dtype=torch.float32)  # 使用线性方差计划。
        self.alpha_bar = torch.cumprod(1.0 - betas, dim=0)  # 预计算各步保留的原始信号比例。

    def train_step(self, model, clean: torch.Tensor, prompts: list[str], optimizer) -> float:  # 执行一次真实梯度更新。
        model.train()  # 启用模型训练模式。
        batch = clean.shape[0]  # 让时间和文本条件与批量对应。
        if batch == 0 or len(prompts) != batch:  # 阻止空批次和错位文本。
            raise ValueError("非空样本批次必须与提示词数量一致")  # 显示明确错误。
        step = torch.randint(0, self.timesteps, (batch,), device=clean.device)  # 对每个样本随机选择噪声等级。
        shape = (batch,) + (1,) * (clean.ndim - 1)  # 准备对图像或视频广播的系数。
        alpha = self.alpha_bar.to(clean.device)[step].reshape(shape)  # 查询累积信号比例。
        noise = torch.randn_like(clean)  # 采样训练目标高斯噪声。
        noisy = alpha.sqrt() * clean + (1.0 - alpha).sqrt() * noise  # 按 DDPM 前向公式加噪。
        prediction = model(noisy, step, prompts)  # 让网络预测刚加入的噪声。
        loss = F.mse_loss(prediction, noise)  # 最小化噪声预测误差。
        optimizer.zero_grad(set_to_none=True)  # 清空上一轮梯度。
        loss.backward()  # 将误差回传给网络参数。
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # 避免小数据集上梯度爆炸。
        optimizer.step()  # 实际更新模型权重。
        return float(loss.detach().cpu())  # 输出可记录的标量训练损失。

    @torch.no_grad()  # 推理阶段不构建梯度图。
    def sample(self, model, shape: tuple[int, ...], prompts: list[str], steps: int = 20, seed: int = 0, guidance: float = 1.0) -> torch.Tensor:  # 从噪声生成潜变量。
        if steps < 1 or steps > self.timesteps:  # 要求推理步数不超过已定义的噪声表。
            raise ValueError("推理步数须位于 1 与训练扩散步数之间")  # 防止重复或越界时间索引。
        if len(shape) not in (4, 5) or shape[0] < 1 or len(prompts) != shape[0]:  # 检查输入形状和提示词对齐。
            raise ValueError("输入须为有效批量图像/视频潜变量，且提示词数量匹配")  # 拒绝不可推理配置。
        if guidance < 0:  # 避免误传负引导系数。
            raise ValueError("引导系数不可为负数")  # 明确参数含义。
        device = next(model.parameters()).device  # 从真实模型读取 CPU/MPS/CUDA 设备。
        generator = torch.Generator(device="cpu").manual_seed(seed)  # 使用 CPU 种子保持跨调用稳定。
        latent = torch.randn(shape, generator=generator, device="cpu").to(device)  # 创建相同种子初始噪声。
        times = torch.linspace(self.timesteps - 1, 0, steps).round().long().tolist()  # 选取降序 DDIM 时间步。
        alpha_bar = self.alpha_bar.to(device)  # 将噪声计划移到模型设备。
        model.eval()  # 关闭潜在的训练态随机层。
        for index, current in enumerate(times):  # 依次逆向消除噪声。
            batch_step = torch.full((shape[0],), current, device=device, dtype=torch.long)  # 构造模型所需时间条件。
            predicted = model(latent, batch_step, prompts)  # 估计有文本条件下的噪声。
            if guidance != 1.0:  # 仅在需要 CFG 时增加一次前向计算。
                unconditional = model(latent, batch_step, [""] * shape[0])  # 估计空提示词噪声。
                predicted = unconditional + guidance * (predicted - unconditional)  # 应用分类器自由引导。
            alpha = alpha_bar[current]  # 获取当前时间步的信号比例。
            previous = times[index + 1] if index + 1 < len(times) else -1  # 最后一步视为原始图像。
            alpha_prev = alpha_bar[previous] if previous >= 0 else torch.ones_like(alpha)  # 为终点使用全信号比例。
            estimate = (latent - (1.0 - alpha).sqrt() * predicted) / alpha.sqrt()  # 根据预测噪声还原干净潜变量。
            latent = alpha_prev.sqrt() * estimate + (1.0 - alpha_prev).sqrt() * predicted  # 执行 eta=0 的确定性 DDIM 更新。
        return latent
CHAPTER 04

文字条件：能输入词，不等于懂中文

文本条件的目的，是让数据里的“红 方块”和图像里的红色方块形成可训练关联。本项目先用空格把一句文本分成短词，再通过 SHA-256 的首字节映射到一个小词表。它只提供稳定索引，不预先理解语义；不同词可能哈希碰撞，训练数据很少时自然无法泛化。

每个词对应一个可训练向量；所有有效词向量取平均，加上时间向量，送进二维或三维去噪器的中层。扩散训练时默认有概率丢弃条件，用于让模型同时学到有词和无词预测。推理可用 CFG：ε = ε_uncond + guidance × (ε_cond − ε_uncond)。引导系数增加只会放大两种预测的差异；模型没学会对应词时不会凭空长出知识。

中文分词提醒：标注和推理应统一用空格拆词，例如 红 衣 女子，否则整句会成为一个哈希 token。短句、统一词表比堆长提示词更适合这个教学模型。
class PromptCondition(nn.Module):  # 轻量哈希词表，仅学习数据集内的文字关联。
    def __init__(self, dim: int):  # 配置条件特征宽度。
        super().__init__()  # 注册可训练词嵌入。
        self.table = nn.Embedding(257, dim, padding_idx=0)  # 0 代表无条件，其他索引代表哈希词。

    def forward(self, prompts: list[str], device: torch.device) -> torch.Tensor:  # 将同批提示词转为条件向量。
        indices = []  # 收集每条文本对应的最多 16 个词。
        for prompt in prompts:  # 对每条文本独立分词。
            words = prompt.lower().strip().split()[:16]  # 用空格分词；中文需数据集自身约定词边界。
            hashed = [hashlib.sha256(word.encode("utf-8")).digest()[0] + 1 for word in words]  # 稳定映射到小词表。
            indices.append(hashed + [0] * (16 - len(hashed)))  # 将不同长度的文本补齐。
        tokens = torch.tensor(indices, dtype=torch.long, device=device)  # 让索引与模型处在同一设备。
        mask = (tokens != 0).unsqueeze(-1)  # 忽略补齐槽位。
        return (self.table(tokens) * mask).sum(dim=1) / mask.sum(dim=1).clamp(min=1)
CHAPTER 05

二维与三维去噪器

图像潜变量张量是 [B, 4, H/4, W/4]；视频潜变量多一根时间轴，形如 [B, 4, T, H/4, W/4]。B 是批大小，T 是固定帧数。二维卷积观察同一画面的相邻像素；三维卷积的核跨相邻帧，所以能够在训练数据中学习有限的运动变化。

每个去噪器都有输入层、空间下采样、中层、上采样、跳跃连接和输出层。三维模式的下采样步幅是 (1,2,2)：只压空间，不压时间。网络的输出维度与加噪潜变量完全相同。没有第一帧控制、长程记忆或人物身份专用模块，不要把“时空卷积”说成成熟的视频模型。

class _ConditionalUNet(nn.Module):  # 二维或三维共用的紧凑条件去噪器。
    def __init__(self, video: bool, base: int = 32):  # 用 video 选择时间轴上的卷积模式。
        super().__init__()  # 注册子网络和训练参数。
        self.video = video  # 记录模型模式供运行时检查。
        self.base = base  # 记录通道数供检查点重建。
        conv = nn.Conv3d if video else nn.Conv2d  # 视频保留显式的帧维度。
        transpose = nn.ConvTranspose3d if video else nn.ConvTranspose2d  # 为视频和图像选择对应的上采样。
        kernel = (3, 3, 3) if video else 3  # 视频卷积覆盖相邻帧。
        padding = (1, 1, 1) if video else 1  # 保持非下采样层的空间尺寸。
        down_kernel = (1, 4, 4) if video else 4  # 下采样只作用于空间维。
        down_stride = (1, 2, 2) if video else 2  # 保持视频帧数原样。
        down_pad = (0, 1, 1) if video else 1  # 使空间尺寸精确减半。
        self.input = conv(4, base, kernel, padding=padding)  # 提取初始潜变量特征。
        self.down = conv(base, base * 2, down_kernel, stride=down_stride, padding=down_pad)  # 构建低分辨率分支。
        self.middle = conv(base * 2, base * 2, kernel, padding=padding)  # 在低分辨率融合邻域信息。
        self.up = transpose(base * 2, base, down_kernel, stride=down_stride, padding=down_pad)  # 恢复输入的空间尺寸。
        self.output = conv(base * 2, 4, kernel, padding=padding)  # 拼接跳连后预测同尺寸噪声。
        self.time = nn.Sequential(nn.Linear(base, base), nn.SiLU(), nn.Linear(base, base))  # 学习时间特征映射。
        self.text = PromptCondition(base)  # 学习文本和目标画面的数据集内关联。
        self.condition = nn.Linear(base, base * 2)  # 将文本与时间投影到低分辨率特征。

    def forward(self, latent: torch.Tensor, timestep: torch.Tensor, prompts: list[str]) -> torch.Tensor:  # 预测潜变量上的噪声。
        expected_dim = 5 if self.video else 4  # 区分批量视频与批量图片。
        if latent.ndim != expected_dim or latent.shape[1] != 4:  # 拒绝输入错误的模型格式。
            raise ValueError(f"预期 {expected_dim} 维且通道为 4 的潜变量")  # 用中文说明失败原因。
        if len(prompts) != latent.shape[0] or timestep.numel() != latent.shape[0]:  # 保证条件逐样本对齐。
            raise ValueError("提示词、时间步与批大小不一致")  # 避免条件静默串样。
        time = self.time(timestep_embedding(timestep, self.base))  # 取得每个样本的扩散时间向量。
        text = self.text(prompts, latent.device)  # 取得每个样本的文本向量。
        shape = (-1, self.base * 2, 1, 1, 1) if self.video else (-1, self.base * 2, 1, 1)  # 选择条件广播形状。
        condition = self.condition(time + text).reshape(shape)  # 把两个条件送入低分辨率特征。
        skip = F.silu(self.input(latent))  # 缓存高分辨率的局部信息。
        hidden = F.silu(self.down(skip) + condition)  # 在低分辨率注入条件。
        hidden = F.silu(self.middle(hidden) + condition)  # 进一步聚合空间或时空上下文。
        hidden = F.silu(self.up(hidden))  # 还原潜变量空间尺寸。
        return self.output(torch.cat([hidden, skip], dim=1))
class ImageDenoiser(_ConditionalUNet):  # 仅沿二维空间进行扩散预测。
    def __init__(self, base: int = 32):  # 允许测试和 GPU 训练采用不同网络宽度。
        super().__init__(video=False, base=base)
class VideoDenoiser(_ConditionalUNet):  # 沿时间和二维空间共同预测噪声。
    def __init__(self, base: int = 32):  # 允许测试和 GPU 训练采用不同网络宽度。
        super().__init__(video=True, base=base)

准备训练材料

把有授权的图片放进 data/images/，MP4 短片放进 data/videos/。同名 UTF-8 .txt 是条件，例如 scene01.mp4 对应 scene01.txt；缺标注会变成空条件。图片和视频帧都先中心裁方，再缩到 VAE 的训练尺寸，像素从 0–255 变到 −1 至 1。

视频数据集顺序读取真正的帧，再均匀抽出指定 --frames 帧。它不会用一张图片冒充视频；但读取超长源视频会先占用内存，所以服务器数据应先切成数秒短片。视频训练不使用原声音轨，导出的视频也无声；配音、字幕与剪辑属于另一条制作流程。

class VideoDataset(Dataset):  # 读取固定帧数的视频片段用于三维扩散训练。
    def __init__(self, folder: str | Path, size: int = 32, frames: int = 4):  # 配置目录和时空尺寸。
        self.folder = Path(folder)  # 归一化数据目录。
        self.size = size  # 保持与 VAE 训练尺寸一致。
        self.frames = frames  # 规定每个样本的时间长度。
        if frames < 2:  # 视频分支要求至少两帧。
            raise ValueError("视频至少需要两帧")  # 阻止伪视频训练。
        self.paths = sorted(self.folder.glob("*.mp4")) if self.folder.is_dir() else []  # 只选择 MP4 数据。
        if not self.paths:  # 防止没有媒体时空转。
            raise ValueError(f"目录中没有 MP4：{self.folder}")  # 标注真实错误来源。

    def __len__(self) -> int:  # 提供真实视频文件数量。
        return len(self.paths)  # 每个文件对应一个训练片段。

    def __getitem__(self, index: int):  # 从实际 MP4 解码并均匀抽帧。
        path = self.paths[index]  # 定位当前视频素材。
        capture = cv2.VideoCapture(str(path))  # 打开 OpenCV 视频解码器。
        if not capture.isOpened():  # 立即检测无法打开的文件。
            raise ValueError(f"无法解码视频：{path}")  # 禁止用静态占位帧掩盖损坏视频。
        frame_count = int(capture.get(cv2.CAP_PROP_FRAME_COUNT))  # 从 MP4 元数据读取帧数而不缓存帧。
        if frame_count < self.frames:  # 媒体没有可靠且足够长的帧数信息时拒绝。
            capture.release()  # 在报错前释放视频句柄。
            raise ValueError(f"视频帧数不足或元数据不可用：{path}")  # 提醒先用 FFmpeg 重封装。
        positions = np.linspace(0, frame_count - 1, self.frames).round().astype(int)  # 在整段时间均匀选帧。
        selected = set(int(position) for position in positions)  # 只为目标帧做图片预处理。
        decoded = {}  # 最多保留用户要求的帧数，不缓存整段视频。
        frame_index = 0  # 为顺序解码的每个真实帧标记索引。
        try:  # 即使解码异常也释放文件句柄。
            while frame_index <= int(positions[-1]):  # 最后一帧取齐后不再读取其余画面。
                ok, frame = capture.read()  # 顺序提取真实压缩视频帧。
                if not ok:  # 播放到片尾或遇到解码错误。
                    break  # 在下方报告缺帧，不制造占位帧。
                if frame_index in selected:  # 只预处理均匀选择的目标帧。
                    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)  # 转为 RGB 顺序。
                    decoded[frame_index] = _prepare(Image.fromarray(rgb), self.size)  # 最多持有目标数量的张量。
                frame_index += 1  # 推进真实视频帧位置。
        finally:  # 不依赖 Python 回收机制管理句柄。
            capture.release()  # 释放操作系统视频资源。
        if len(decoded) != self.frames:  # 核对容器声称的帧数与真实可解码帧数。
            raise ValueError(f"视频实际可解码帧数不足 {self.frames}：{path}")  # 防止损坏 MP4 被静默补帧。
        clip = torch.stack([decoded[int(position)] for position in positions], dim=1)  # 形成 [C,T,H,W] 视频片段。
        return clip, _caption(path)

"""轻量 VAE 与图像/视频去噪网络：所有权重均从零初始化。"""

import hashlib  # 使用稳定摘要将短文本映射到可训练的词表索引。
import math  # 构造正弦时间嵌入所需的频率。

import torch  # 提供张量、设备与随机采样。
from torch import nn  # 提供神经网络组件。
from torch.nn import functional as F  # 提供插值与激活函数。


class TinyVAE(nn.Module):  # 将像素压到四分之一空间分辨率的变分自编码器。
    def __init__(self, base: int = 32, latent_channels: int = 4):  # 允许按显存缩放宽度。
        super().__init__()  # 注册父类的参数管理能力。
        self.base = base  # 保留宽度以便写入检查点配置。
        self.latent_channels = latent_channels  # 保留潜变量通道配置。
        self.encoder = nn.Sequential(  # 建立两次下采样的像素编码器。
            nn.Conv2d(3, base, 3, padding=1), nn.SiLU(),  # 将 RGB 投影到隐藏特征。
            nn.Conv2d(base, base, 4, stride=2, padding=1), nn.SiLU(),  # 将边长减半。
            nn.Conv2d(base, base * 2, 4, stride=2, padding=1), nn.SiLU(),  # 再将边长减半。
            nn.Conv2d(base * 2, latent_channels * 2, 3, padding=1),  # 同时预测均值与对数方差。
        )  # 完成编码器定义。
        self.decoder = nn.Sequential(  # 建立与编码器空间尺寸对应的解码器。
            nn.Conv2d(latent_channels, base * 2, 3, padding=1), nn.SiLU(),  # 扩展潜变量通道。
            nn.ConvTranspose2d(base * 2, base, 4, stride=2, padding=1), nn.SiLU(),  # 恢复两倍边长。
            nn.ConvTranspose2d(base, base, 4, stride=2, padding=1), nn.SiLU(),  # 再恢复两倍边长。
            nn.Conv2d(base, 3, 3, padding=1), nn.Tanh(),  # 输出 [-1,1] 的 RGB 像素。
        )  # 完成解码器定义。

    def encode(self, image: torch.Tensor, sample: bool = True):  # 返回潜变量及分布参数。
        mean, logvar = self.encoder(image).chunk(2, dim=1)  # 沿通道拆出均值和对数方差。
        logvar = logvar.clamp(-10.0, 10.0)  # 防止标准差溢出或数值下溢。
        z = mean + torch.exp(0.5 * logvar) * torch.randn_like(mean) if sample else mean  # 训练时重参数化，推理时取均值。
        return z, mean, logvar  # 交还可用于重建与 KL 损失的量。

    def decode(self, latent: torch.Tensor) -> torch.Tensor:  # 从潜变量还原 RGB 图像。
        return self.decoder(latent)  # 输出范围由 Tanh 保证为 [-1,1]。

    def forward(self, image: torch.Tensor):  # 统一提供训练所需的重建结果。
        z, mean, logvar = self.encode(image)  # 执行变分编码。
        return self.decode(z), mean, logvar  # 将重建与分布参数交给损失函数。


def timestep_embedding(timestep: torch.Tensor, dim: int) -> torch.Tensor:  # 生成确定性的扩散时间特征。
    half = dim // 2  # 为正弦与余弦各留一半通道。
    freqs = torch.exp(-math.log(10000) * torch.arange(half, device=timestep.device) / max(half - 1, 1))  # 建立对数间隔频率。
    phase = timestep.float()[:, None] * freqs[None, :]  # 将每个时间步乘以频率。
    embedding = torch.cat([phase.sin(), phase.cos()], dim=-1)  # 拼合正弦和余弦特征。
    return F.pad(embedding, (0, dim % 2))  # 奇数维时补一个通道。


class PromptCondition(nn.Module):  # 轻量哈希词表，仅学习数据集内的文字关联。
    def __init__(self, dim: int):  # 配置条件特征宽度。
        super().__init__()  # 注册可训练词嵌入。
        self.table = nn.Embedding(257, dim, padding_idx=0)  # 0 代表无条件，其他索引代表哈希词。

    def forward(self, prompts: list[str], device: torch.device) -> torch.Tensor:  # 将同批提示词转为条件向量。
        indices = []  # 收集每条文本对应的最多 16 个词。
        for prompt in prompts:  # 对每条文本独立分词。
            words = prompt.lower().strip().split()[:16]  # 用空格分词；中文需数据集自身约定词边界。
            hashed = [hashlib.sha256(word.encode("utf-8")).digest()[0] + 1 for word in words]  # 稳定映射到小词表。
            indices.append(hashed + [0] * (16 - len(hashed)))  # 将不同长度的文本补齐。
        tokens = torch.tensor(indices, dtype=torch.long, device=device)  # 让索引与模型处在同一设备。
        mask = (tokens != 0).unsqueeze(-1)  # 忽略补齐槽位。
        return (self.table(tokens) * mask).sum(dim=1) / mask.sum(dim=1).clamp(min=1)  # 对真实词取平均。


class _ConditionalUNet(nn.Module):  # 二维或三维共用的紧凑条件去噪器。
    def __init__(self, video: bool, base: int = 32):  # 用 video 选择时间轴上的卷积模式。
        super().__init__()  # 注册子网络和训练参数。
        self.video = video  # 记录模型模式供运行时检查。
        self.base = base  # 记录通道数供检查点重建。
        conv = nn.Conv3d if video else nn.Conv2d  # 视频保留显式的帧维度。
        transpose = nn.ConvTranspose3d if video else nn.ConvTranspose2d  # 为视频和图像选择对应的上采样。
        kernel = (3, 3, 3) if video else 3  # 视频卷积覆盖相邻帧。
        padding = (1, 1, 1) if video else 1  # 保持非下采样层的空间尺寸。
        down_kernel = (1, 4, 4) if video else 4  # 下采样只作用于空间维。
        down_stride = (1, 2, 2) if video else 2  # 保持视频帧数原样。
        down_pad = (0, 1, 1) if video else 1  # 使空间尺寸精确减半。
        self.input = conv(4, base, kernel, padding=padding)  # 提取初始潜变量特征。
        self.down = conv(base, base * 2, down_kernel, stride=down_stride, padding=down_pad)  # 构建低分辨率分支。
        self.middle = conv(base * 2, base * 2, kernel, padding=padding)  # 在低分辨率融合邻域信息。
        self.up = transpose(base * 2, base, down_kernel, stride=down_stride, padding=down_pad)  # 恢复输入的空间尺寸。
        self.output = conv(base * 2, 4, kernel, padding=padding)  # 拼接跳连后预测同尺寸噪声。
        self.time = nn.Sequential(nn.Linear(base, base), nn.SiLU(), nn.Linear(base, base))  # 学习时间特征映射。
        self.text = PromptCondition(base)  # 学习文本和目标画面的数据集内关联。
        self.condition = nn.Linear(base, base * 2)  # 将文本与时间投影到低分辨率特征。

    def forward(self, latent: torch.Tensor, timestep: torch.Tensor, prompts: list[str]) -> torch.Tensor:  # 预测潜变量上的噪声。
        expected_dim = 5 if self.video else 4  # 区分批量视频与批量图片。
        if latent.ndim != expected_dim or latent.shape[1] != 4:  # 拒绝输入错误的模型格式。
            raise ValueError(f"预期 {expected_dim} 维且通道为 4 的潜变量")  # 用中文说明失败原因。
        if len(prompts) != latent.shape[0] or timestep.numel() != latent.shape[0]:  # 保证条件逐样本对齐。
            raise ValueError("提示词、时间步与批大小不一致")  # 避免条件静默串样。
        time = self.time(timestep_embedding(timestep, self.base))  # 取得每个样本的扩散时间向量。
        text = self.text(prompts, latent.device)  # 取得每个样本的文本向量。
        shape = (-1, self.base * 2, 1, 1, 1) if self.video else (-1, self.base * 2, 1, 1)  # 选择条件广播形状。
        condition = self.condition(time + text).reshape(shape)  # 把两个条件送入低分辨率特征。
        skip = F.silu(self.input(latent))  # 缓存高分辨率的局部信息。
        hidden = F.silu(self.down(skip) + condition)  # 在低分辨率注入条件。
        hidden = F.silu(self.middle(hidden) + condition)  # 进一步聚合空间或时空上下文。
        hidden = F.silu(self.up(hidden))  # 还原潜变量空间尺寸。
        return self.output(torch.cat([hidden, skip], dim=1))  # 输出真实网络预测的噪声。

"""DDPM 噪声学习与 DDIM 无随机反向采样。"""

import torch  # 提供随机采样、张量运算和梯度能力。
from torch.nn import functional as F  # 提供均方误差损失。


class Diffusion:  # 保留独立于模型权重的扩散噪声时间表。
    def __init__(self, timesteps: int = 100):  # 配置训练扩散的离散步数。
        if timesteps < 2:  # 避免只有一步时无法定义有效噪声过程。
            raise ValueError("扩散步数至少为 2")  # 提示可修复的配置错误。
        self.timesteps = timesteps  # 记录检查点必须复现的训练参数。
        betas = torch.linspace(0.0001, 0.02, timesteps, dtype=torch.float32)  # 使用线性方差计划。
        self.alpha_bar = torch.cumprod(1.0 - betas, dim=0)  # 预计算各步保留的原始信号比例。

    def train_step(self, model, clean: torch.Tensor, prompts: list[str], optimizer) -> float:  # 执行一次真实梯度更新。
        model.train()  # 启用模型训练模式。
        batch = clean.shape[0]  # 让时间和文本条件与批量对应。
        if batch == 0 or len(prompts) != batch:  # 阻止空批次和错位文本。
            raise ValueError("非空样本批次必须与提示词数量一致")  # 显示明确错误。
        step = torch.randint(0, self.timesteps, (batch,), device=clean.device)  # 对每个样本随机选择噪声等级。
        shape = (batch,) + (1,) * (clean.ndim - 1)  # 准备对图像或视频广播的系数。
        alpha = self.alpha_bar.to(clean.device)[step].reshape(shape)  # 查询累积信号比例。
        noise = torch.randn_like(clean)  # 采样训练目标高斯噪声。
        noisy = alpha.sqrt() * clean + (1.0 - alpha).sqrt() * noise  # 按 DDPM 前向公式加噪。
        prediction = model(noisy, step, prompts)  # 让网络预测刚加入的噪声。
        loss = F.mse_loss(prediction, noise)  # 最小化噪声预测误差。
        optimizer.zero_grad(set_to_none=True)  # 清空上一轮梯度。
        loss.backward()  # 将误差回传给网络参数。
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # 避免小数据集上梯度爆炸。
        optimizer.step()  # 实际更新模型权重。
        return float(loss.detach().cpu())  # 输出可记录的标量训练损失。

    @torch.no_grad()  # 推理阶段不构建梯度图。
    def sample(self, model, shape: tuple[int, ...], prompts: list[str], steps: int = 20, seed: int = 0, guidance: float = 1.0) -> torch.Tensor:  # 从噪声生成潜变量。
        if steps < 1 or steps > self.timesteps:  # 要求推理步数不超过已定义的噪声表。
            raise ValueError("推理步数须位于 1 与训练扩散步数之间")  # 防止重复或越界时间索引。
        if len(shape) not in (4, 5) or shape[0] < 1 or len(prompts) != shape[0]:  # 检查输入形状和提示词对齐。
            raise ValueError("输入须为有效批量图像/视频潜变量，且提示词数量匹配")  # 拒绝不可推理配置。
        if guidance < 0:  # 避免误传负引导系数。
            raise ValueError("引导系数不可为负数")  # 明确参数含义。
        device = next(model.parameters()).device  # 从真实模型读取 CPU/MPS/CUDA 设备。
        generator = torch.Generator(device="cpu").manual_seed(seed)  # 使用 CPU 种子保持跨调用稳定。
        latent = torch.randn(shape, generator=generator, device="cpu").to(device)  # 创建相同种子初始噪声。
        times = torch.linspace(self.timesteps - 1, 0, steps).round().long().tolist()  # 选取降序 DDIM 时间步。
        alpha_bar = self.alpha_bar.to(device)  # 将噪声计划移到模型设备。
        model.eval()  # 关闭潜在的训练态随机层。
        for index, current in enumerate(times):  # 依次逆向消除噪声。
            batch_step = torch.full((shape[0],), current, device=device, dtype=torch.long)  # 构造模型所需时间条件。
            predicted = model(latent, batch_step, prompts)  # 估计有文本条件下的噪声。
            if guidance != 1.0:  # 仅在需要 CFG 时增加一次前向计算。
                unconditional = model(latent, batch_step, [""] * shape[0])  # 估计空提示词噪声。
                predicted = unconditional + guidance * (predicted - unconditional)  # 应用分类器自由引导。
            alpha = alpha_bar[current]  # 获取当前时间步的信号比例。
            previous = times[index + 1] if index + 1 < len(times) else -1  # 最后一步视为原始图像。
            alpha_prev = alpha_bar[previous] if previous >= 0 else torch.ones_like(alpha)  # 为终点使用全信号比例。
            estimate = (latent - (1.0 - alpha).sqrt() * predicted) / alpha.sqrt()  # 根据预测噪声还原干净潜变量。
            latent = alpha_prev.sqrt() * estimate + (1.0 - alpha_prev).sqrt() * predicted  # 执行 eta=0 的确定性 DDIM 更新。
        return latent  # 返回供 VAE 解码的潜变量。

def _prepare(image: Image.Image, size: int) -> torch.Tensor:  # 对图片和视频帧执行相同预处理。
    if size < 16 or size % 4:  # 确保 VAE 两次下采样后仍有有效尺寸。
        raise ValueError("图片边长须大于等于 16 且可被 4 整除")  # 及早拒绝坏配置。
    image = image.convert("RGB")  # 统一输入到三通道 RGB。
    side = min(image.size)  # 找到可裁剪的最大中心方形边长。
    left = (image.width - side) // 2  # 计算中心裁剪的左边界。
    top = (image.height - side) // 2  # 计算中心裁剪的上边界。
    image = image.crop((left, top, left + side, top + side))  # 保持主体的中心部分。
    image = image.resize((size, size), Image.Resampling.LANCZOS)  # 统一训练画幅。
    array = np.asarray(image, dtype=np.float32).copy()  # 转换为可写的浮点数组。
    return torch.from_numpy(array).permute(2, 0, 1) / 127.5 - 1.0  # 输出 CHW 且范围为 [-1,1]。


def _caption(path: Path) -> str:  # 读取与媒体同名的短文字说明。

class VideoDataset(Dataset):  # 读取固定帧数的视频片段用于三维扩散训练。
    def __init__(self, folder: str | Path, size: int = 32, frames: int = 4):  # 配置目录和时空尺寸。
        self.folder = Path(folder)  # 归一化数据目录。
        self.size = size  # 保持与 VAE 训练尺寸一致。
        self.frames = frames  # 规定每个样本的时间长度。
        if frames < 2:  # 视频分支要求至少两帧。
            raise ValueError("视频至少需要两帧")  # 阻止伪视频训练。
        self.paths = sorted(self.folder.glob("*.mp4")) if self.folder.is_dir() else []  # 只选择 MP4 数据。
        if not self.paths:  # 防止没有媒体时空转。
            raise ValueError(f"目录中没有 MP4：{self.folder}")  # 标注真实错误来源。

    def __len__(self) -> int:  # 提供真实视频文件数量。
        return len(self.paths)  # 每个文件对应一个训练片段。

    def __getitem__(self, index: int):  # 从实际 MP4 解码并均匀抽帧。
        path = self.paths[index]  # 定位当前视频素材。
        capture = cv2.VideoCapture(str(path))  # 打开 OpenCV 视频解码器。
        if not capture.isOpened():  # 立即检测无法打开的文件。
            raise ValueError(f"无法解码视频：{path}")  # 禁止用静态占位帧掩盖损坏视频。
        frame_count = int(capture.get(cv2.CAP_PROP_FRAME_COUNT))  # 从 MP4 元数据读取帧数而不缓存帧。
        if frame_count < self.frames:  # 媒体没有可靠且足够长的帧数信息时拒绝。
            capture.release()  # 在报错前释放视频句柄。
            raise ValueError(f"视频帧数不足或元数据不可用：{path}")  # 提醒先用 FFmpeg 重封装。
        positions = np.linspace(0, frame_count - 1, self.frames).round().astype(int)  # 在整段时间均匀选帧。
        selected = set(int(position) for position in positions)  # 只为目标帧做图片预处理。
        decoded = {}  # 最多保留用户要求的帧数，不缓存整段视频。
        frame_index = 0  # 为顺序解码的每个真实帧标记索引。
        try:  # 即使解码异常也释放文件句柄。
            while frame_index <= int(positions[-1]):  # 最后一帧取齐后不再读取其余画面。
                ok, frame = capture.read()  # 顺序提取真实压缩视频帧。
                if not ok:  # 播放到片尾或遇到解码错误。
                    break  # 在下方报告缺帧，不制造占位帧。
                if frame_index in selected:  # 只预处理均匀选择的目标帧。
                    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)  # 转为 RGB 顺序。
                    decoded[frame_index] = _prepare(Image.fromarray(rgb), self.size)  # 最多持有目标数量的张量。
                frame_index += 1  # 推进真实视频帧位置。
        finally:  # 不依赖 Python 回收机制管理句柄。
            capture.release()  # 释放操作系统视频资源。
        if len(decoded) != self.frames:  # 核对容器声称的帧数与真实可解码帧数。
            raise ValueError(f"视频实际可解码帧数不足 {self.frames}：{path}")  # 防止损坏 MP4 被静默补帧。
        clip = torch.stack([decoded[int(position)] for position in positions], dim=1)  # 形成 [C,T,H,W] 视频片段。
        return clip, _caption(path)  # 返回真实片段及配对提示词。

    for local_step in range(args.steps):  # 执行明确要求的新增训练步骤。
        pixels, prompts = next(loader)  # 从真实数据集中读媒体和标注。
        with torch.no_grad():  # 不更新 VAE 参数或缓存无用梯度。
            source = _images(pixels) if video else pixels  # 视频以同一个 VAE 编码逐帧图像。
            latent, _, _ = vae.encode(source.to(device), sample=False)  # 获取确定性的媒体潜变量。
            if video:  # 视频模型还原完整的时间维度。
                latent = _videos(latent, pixels.shape[0], pixels.shape[2])  # 在潜空间连接相邻帧。
        prompts = [prompt if torch.rand(()) >= args.condition_dropout else "" for prompt in prompts]  # 用随机空条件训练 CFG 分支。
        loss = schedule.train_step(model, latent, prompts, optimizer)  # 执行实际噪声预测梯度更新。
        if local_step % max(1, args.steps // 20) == 0:  # 定期反馈可验证训练进度。
            print(f"{kind} 步数 {finished + local_step + 1}，噪声损失 {loss:.5f}", flush=True)  # 不将损失当成画质指标。
    payload = {"kind": kind, "size": size, "base": args.base, "diffusion_steps": args.diffusion_steps, "model": model.state_dict(), "optimizer": optimizer.state_dict(), "step": finished + args.steps}  # 封装完整恢复信息。
    if video:  # 视频权重需记录固定推理帧数。
        payload["frames"] = args.frames  # 保证训练与推理时序一致。
    _save(args.out, payload)  # 原子保存已训练的模型检查点。
    print(f"已保存 {kind} 模型：{args.out}", flush=True)  # 回报真实生成文件位置。


def _to_rgb(tensor: torch.Tensor) -> np.ndarray:  # 将 VAE 的 [-1,1] 输出转换成无符号 RGB。
    pixels = ((tensor.detach().cpu().clamp(-1, 1) + 1) * 127.5).round().to(torch.uint8)  # 限制溢出并量化为 8 位。
    return pixels.permute(1, 2, 0).numpy()  # 转换为编码器期望的 HWC 顺序。


def sample(args, video: bool) -> None:  # 从训练后的图像或视频检查点推理。
    device = _device(args.device)  # 选择 CPU 或现有 GPU。
    vae_checkpoint = _load(args.vae, "vae")  # 加载共享潜空间解码器。
    kind = "video" if video else "image"  # 决定所需模型类型。
    checkpoint = _load(args.model, kind)  # 严格禁止交叉使用权重。
    if vae_checkpoint["size"] != checkpoint["size"]:  # 检查推理阶段的像素尺寸一致性。
        raise ValueError("VAE 与扩散模型的尺寸不一致")  # 阻止损坏或错误的输出。
    vae = TinyVAE(base=vae_checkpoint["base"]).to(device)  # 重建对应架构的 VAE。
    vae.load_state_dict(vae_checkpoint["model"])  # 装载实际训练过的解码权重。
    vae.eval()  # 以固定模型行为推理。
    model = (VideoDenoiser(base=checkpoint["base"]) if video else ImageDenoiser(base=checkpoint["base"])).to(device)  # 重建正确的去噪网络。
    model.load_state_dict(checkpoint["model"])  # 装载真实训练检查点。
    schedule = Diffusion(timesteps=checkpoint["diffusion_steps"])  # 复现与训练一致的噪声计划。
    size = checkpoint["size"]  # 从训练检查点确定输出画幅。
    shape = (1, 4, checkpoint["frames"], size // 4, size // 4) if video else (1, 4, size // 4, size // 4)  # 明确潜变量的时空形状。
    latent = schedule.sample(model, shape, [args.prompt], steps=args.sample_steps, seed=args.seed, guidance=args.guidance)  # 完成真正的 DDIM 反向采样。
    destination = Path(args.out)  # 归一化媒体输出路径。
    destination.parent.mkdir(parents=True, exist_ok=True)  # 创建属于此任务的输出目录。
    with torch.no_grad():  # 解码不需保存梯度。
        decoded = vae.decode(_images(latent) if video else latent)  # 视频逐帧解码共用的 VAE。
    if not video:  # 图像直接保存单张 PNG。
        Image.fromarray(_to_rgb(decoded[0])).save(destination, format="PNG")  # 写出可由 PIL 打开的真实图片。
    else:  # 视频使用 FFmpeg 将实际生成帧编码成 MP4。
        frames = np.stack([_to_rgb(frame) for frame in decoded], axis=0)  # 构造 [T,H,W,RGB] 连续帧。
        command = ["ffmpeg", "-y", "-loglevel", "error", "-f", "rawvideo", "-pix_fmt", "rgb24", "-s", f"{size}x{size}", "-r", str(args.fps), "-i", "pipe:0", "-an", "-c:v", "libx264", "-pix_fmt", "yuv420p", "-movflags", "+faststart", str(destination)]  # 显式选择无声 H.264 兼容输出。
        subprocess.run(command, input=frames.tobytes(), capture_output=True, check=True)  # 任何编码失败均返回真实错误。
    print(f"已生成 {kind}：{destination}", flush=True)  # 回报已完成的文件路径。


def main() -> None:  # 解析命令并分派到正确的训练/推理流程。
    parser = argparse.ArgumentParser(description="Mini SD：从零训练的轻量图像/视频潜扩散实验")  # 提供用户可发现的帮助。
    commands = parser.add_subparsers(dest="command", required=True)  # 创建互斥子命令。
    for name in ("train-vae", "train-image", "train-video", "sample-image", "sample-video"):  # 逐项建立命令参数。
        sub = commands.add_parser(name)  # 创建命令专属解析器。
        sub.add_argument("--device", choices=("auto", "cpu", "mps", "cuda"), default="auto")  # 允许明确指定设备。
        if name.startswith("train"):  # 训练命令需要数据集和优化配置。
            sub.add_argument("--data", required=True)  # 指定输入训练媒体目录。
            sub.add_argument("--steps", type=int, default=100)  # 指定新增梯度更新次数。
            sub.add_argument("--batch-size", type=int, default=1)  # 控制显存占用。
            sub.add_argument("--lr", type=float, default=0.0002)  # 指定优化器学习率。
            sub.add_argument("--base", type=int, default=32)  # 指定网络宽度。
            sub.add_argument("--resume")  # 可选恢复已有的同类检查点。
            sub.add_argument("--out", required=True)  # 指定新检查点文件路径。
        if name != "train-vae":  # 扩散训练与所有采样都需要 VAE 权重。
            sub.add_argument("--vae", required=True)  # 指定预训练的本项目 VAE。
        if name == "train-vae":  # VAE 阶段需要显式确定像素尺寸。
            sub.add_argument("--size", type=int, default=32)  # 默认教学用小画幅。
            sub.add_argument("--kl-weight", type=float, default=0.001)  # 控制潜变量正则强度。
        if name in ("train-image", "train-video"):  # 扩散训练独有的噪声参数。
            sub.add_argument("--diffusion-steps", type=int, default=100)  # 固定训练噪声计划长度。
            sub.add_argument("--condition-dropout", type=float, default=0.1)  # 为 CFG 训练空条件分支。
        if name == "train-video":  # 三维模型需要固定时间长度。
            sub.add_argument("--frames", type=int, default=4)  # 默认生成短片段以适配小显存。
        if name.startswith("sample"):  # 推理命令需要模型与提示词。
            sub.add_argument("--model", required=True)  # 指定图像或视频扩散检查点。
            sub.add_argument("--out", required=True)  # 指定 PNG 或 MP4 输出路径。
            sub.add_argument("--prompt", default="")  # 指定本训练集对应的短文本条件。
            sub.add_argument("--sample-steps", type=int, default=20)  # 控制 DDIM 推理步数。
            sub.add_argument("--seed", type=int, default=0)  # 允许固定随机种子。
            sub.add_argument("--guidance", type=float, default=1.0)  # 控制文本 CFG 权重。
        if name == "sample-video":  # 视频容器还需要播放帧率。
            sub.add_argument("--fps", type=int, default=8)  # 指定无声输出播放速度。
    args = parser.parse_args()  # 真正读取命令行输入。
    if args.command.startswith("train"):  # 训练前统一检查数值边界。
        if args.steps < 1 or args.batch_size < 1 or args.lr <= 0 or args.base < 4:  # 阻止不可能完成的训练配置。
            parser.error("steps/batch-size 必须为正，lr 须大于零，base 至少为 4")  # 报错而非写入空模型。
    if args.command == "train-vae":  # 将训练限制在指定 VAE 功能。
        train_vae(args)  # 执行实际 VAE 训练。
    elif args.command in ("train-image", "train-video"):  # 区分不同维度的扩散网络。
        if not 0 <= args.condition_dropout <= 1:  # 拒绝无效概率。
            parser.error("condition-dropout 必须位于 0 到 1")  # 显示配置错误。
        train_diffusion(args, video=args.command == "train-video")  # 执行实际噪声训练。
    else:  # 剩余子命令均为媒体推理。
        if args.command == "sample-video" and args.fps < 1:  # 防止视频帧率非法。
            parser.error("fps 至少为 1")  # 在解码前给出可读错误。
        sample(args, video=args.command == "sample-video")  # 输出 PNG 或 MP4。


if __name__ == "__main__":  # 支持以 Python 模块方式直接运行。
    main()  # 执行命令行入口。
